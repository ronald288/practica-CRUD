# practica-CRUD
Proyecto práctico de gestión de usuarios desarrollado con Node.js, Express y MySQL
permite registrar usuarios con nombre, correo electrónico y contraseña. Implementa las operaciones CRUD (Crear, Leer, Actualizar y Eliminar), mediante una API RESTful, aplicando validaciones y manejo de errores. Incluye almacenamiento de datos en MySQL y encriptación de contraseñas para reforzar la seguridad de la información.
